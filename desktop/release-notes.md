# nod <versão>

App desktop do nod para macOS (Intel `x64` e chip M `arm64`): conecta este Mac ao servidor do time e roda os turnos dos agentes com o Claude Code ou o Codex instalado nele.
Antes de publicar, troque este texto pelas mudanças da versão e preencha o registro abaixo; instalação, requisitos e atualização estão no [guia do desktop](https://github.com/gamefik/nod/blob/main/docs/release-desktop.md).
